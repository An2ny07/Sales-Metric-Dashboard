# Sales Metric Dashboard
A simple and beginner-friendly Sales Metrics Dashboard project designed to explore sales data, track key performance indicators, and practice data visualization skills. Built to improve understanding of sales trends, revenue performance, and customer insights using clean and organized visuals.

## Project Objective:
The objective of this project is to develop a fully interactive and visually cohesive Power BI dashboard that consolidates essential sales metrics including monthly revenue trends, total sales and profit performance, top selling products, regional profit distribution, order type insights, and year-over-year comparisons into a single analytical platform designed to enhance business transparency, support strategic decision-making, streamline reporting processes, and empower stakeholders with accurate, real-time data for improved operational and financial planning.

## Questions (KPIs):
- What are our total sales, revenue, and profit?
- How many units did we sell overall?
- Which months had the highest and lowest revenue?
- Which products are our top sellers?
- Which region is performing the best?
- Do we sell more through in-store or online orders?
- How does this year’s sales compare to last year?
